# License glossary

Short summaries of the licenses that appear as destinations in the record. These are orientation notes, not legal advice; always read the license text itself.

## SSPL {#sspl}

**Server Side Public License.** Published by MongoDB in 2018. It is based on the AGPL-3.0, but if you offer the software as a service, you must release the source of the entire stack used to run that service, including management, monitoring and backup tooling. MongoDB submitted it to the OSI and later withdrew it; it is not OSI-approved.

[License text](https://www.mongodb.com/legal/licensing/server-side-public-license)

## BUSL {#busl}

**Business Source License 1.1** (also abbreviated BSL). Created by MariaDB. Source is published, but production use is restricted except as allowed by an "Additional Use Grant" each licensor writes. Each release converts to a named open source license on a "Change Date", no more than four years after release. Not OSI-approved.

[License text](https://mariadb.com/bsl11/)

## Elastic License v2 {#elv2}

**Elastic License 2.0 (ELv2).** Published by Elastic in 2021. Permits most use, but prohibits offering the software as a managed service and circumventing license-key functionality. Not OSI-approved.

[License text](https://www.elastic.co/licensing/elastic-license)

## Commons Clause {#commons-clause}

**Commons Clause.** Not a full license but a condition added on top of an existing one, usually Apache-2.0. It removes the right to "sell" the software, defined broadly enough to cover hosting or support offerings whose value derives substantially from it. A license with the clause attached is not OSI-approved.

[Clause text](https://commonsclause.com/)

## Confluent Community License {#confluent}

Published by Confluent in 2018 for parts of the Confluent Platform. Allows use and modification, but prohibits offering the covered components as a SaaS product that competes with Confluent. Not OSI-approved.

[License text](https://www.confluent.io/confluent-community-license/)

## Timescale License {#timescale}

**Timescale License (TSL).** Applies to TimescaleDB's community features. Permits use and modification, but prohibits offering TimescaleDB as a hosted database-as-a-service. Not OSI-approved.

[License text](https://github.com/timescale/timescaledb/blob/main/tsl/LICENSE-TIMESCALE)

## AGPL-3.0 {#agpl}

**GNU Affero General Public License v3.** An OSI-approved, strong copyleft license. It extends the GPL so that users who interact with modified software over a network must be offered its source. Moving to AGPL keeps a project open source, but it changes obligations significantly for anyone embedding or hosting it.

[License text](https://www.gnu.org/licenses/agpl-3.0.html)
